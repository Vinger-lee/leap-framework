01 · TEACHING · 教学内容

阶乘递归：基线条件与递归条件

学完这一节，你能读懂并补全任意简单递归函数，并说清调用栈的「展开 → 命中基线 → 回退求值」全过程。

预计 12 分钟　·　难度 2/5　·　先修：函数定义与返回值

递归函数把一个问题拆成同类型、但规模更小的子问题，直到小到可以直接回答为止。这个「小到可以直接回答」的情形，就是基线条件（base case）。缺少基线条件的递归会一直往下展开，永远不会开始回退。

递归 = 先把问题拆到基线，再一层层回来算。
基线条件决定什么时候停，递归条件决定怎么变小。

两个条件缺一不可

  • ①　基线条件 —— n <= 1 时直接返回 1，递归在这里停止。
  • ②　递归条件 —— 把 factorial(n) 化为 n × factorial(n-1)，规模每次减 1。
CHECKPOINT · 理解检查

如果删掉 factorial 的基线条件，Python 会发生什么？

KEY FORM · 关键式子 factorial(n) = n × factorial(n-1) factorial(0) = 1　（等价写法 n <= 1）

墨色 = 递归条件，绿色 = 基线条件。

MISCONCEPTION · 常见误解

「递归就是自己调用自己」——这句话只说对了一半。真正让递归成立的是基线的存在；只有「调用自己」的那部分是死循环。
