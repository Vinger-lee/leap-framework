01 · TEACHING · 教学内容

条件概率：先看分母，再看基率

用四格表、频数条和概率树把“已知”变成可见的样本范围，区分 P(A|B) 与 P(B|A)，判断独立性，并解释阳性结果为何受基率影响。

建议 35–50 分钟 · 先修：分数、百分比、集合交集与补集的直觉

LEARNING RESOURCES · 搜索关键词

核心 / 必看：“条件概率 自然频数 四格表”“P A given B 分母”“贝叶斯公式 基率忽视 筛查阳性”。

拓展 / 辅助：“概率树 全概率公式 敏感度 特异度”“独立事件 与 互斥事件 区别”“医学筛查 阳性预测值”。

进阶 / 深入：“Bayes odds likelihood ratio”“conditional probability zero probability events”“selection bias conditional independence”。

可复制到 B 站、课程平台或搜索引擎检索。这里提供检索关键词，不声称某条视频已经核验；优先选择能说明四格人数及分母、而不是只背公式的课程。

先修：事件、交集与同一总体

事件 A 是“有病”，事件 B 是“检测阳性”。A∩B 是“有病且阳性”；Ā 是“无病”，B̄ 是“阴性”。四种组合互不重叠，合起来覆盖总体。下面使用同一总体的 10,000 人，默认模型把随机选人视为等可能；不能把来自不同人群的分子与分母随意拼在一起。

条件概率把观察范围缩小到“条件已成立”的人群。P(A|B) 读作“已知 B，A 的概率”；竖线右边是条件，所以分母必须是 B 的全部人数。

1. 三个概率，各回答不同问题

符号具体问题对应分母
P(A)随机选一人，有病的概率是多少？这是基率/患病率。所有人
P(B|A)只看有病者，检测阳性的比例是多少？这是敏感度。所有有病者
P(A|B)只看阳性者，真正有病的比例是多少？这是阳性预测值。所有阳性者：真阳性 + 假阳性
P(A|B)=P(A∩B)P(B),P(B)>0

注意方向：P(A|B) 和 P(B|A) 有相同交集，却使用不同分母。只有满足额外数值关系时才可能相等；“检测对病人的敏感度高”不能直接推出“阳性者有病的概率高”。

2. 完整频数推导：1% 基率，90% 敏感度，9% 假阳性率

  1. 10,000 人中，有病 100、无病 9,900。
  2. 有病者 90% 阳性：真阳性 90，假阴性 10。
  3. 无病者 9% 阳性：假阳性 891，真阴性 9,009。
  4. 阳性者总数 90+891=981；因此 P(A|B)=90/981=10/109≈9.17%。
  5. 敏感度 P(B|A)=90/100=90%；两者分母是 981 与 100，不能互换。

这些人数是给定概率模型对应的频数/期望人数，用于理解比例，不代表已经观察到的真实病例。这里滑块使用整数百分比，固定 10,000 人，使四格计数为整数。真实样本会有随机波动，参数还可能随人群而变。

特异度与假阳性率：特异度 P(B̄|Ā)=1−P(B|Ā)。本例假阳性率 9%，特异度 91%。它们的条件都是“无病”，不是“所有阳性”，也不是“所有人”。

3. 从四格表得到全概率与贝叶斯公式

B 的人数来自有病与无病两个互斥分支，所以先把两条路径相乘，再相加：P(B)=P(B|A)P(A)+P(B|Ā)P(Ā)。把这一结果用作条件概率的分母，得到贝叶斯公式。

P(A|B)=P(B|A)P(A)P(B|A)P(A)+P(B|A¯)P(A¯)

保持敏感度 90%、假阳性率 9%，把基率从 1% 改为 10%：真阳性 900，假阳性 810，阳性总数 1,710，P(A|B)=900/1710=10/19≈52.63%。同一检测参数，应用在人群中不同基率，阳性预测值不同。

4. 独立、互斥与零分母

独立表示知道一个事件不改变另一个事件的概率，通用定义是 P(A∩B)=P(A)P(B)。若 P(B)>0，可等价写为 P(A|B)=P(A)。在两个健康状态分支都有正概率时，敏感度等于假阳性率意味着检测结果不区分有病与无病。

互斥表示不能同时发生，即 A∩B 为空。若 P(A)、P(B) 均大于 0，互斥会使 P(A∩B)=0 而 P(A)P(B)>0，因此它们不独立。独立也不等于因果无关，统计关联也不等于因果作用。

边界：P(B)=0 时，本页的离散比例 P(A|B) 无定义，不能填 0、1 或“永远独立所以随便取”。若 P(A)=0，P(B|A) 也无定义；若全员阳性，则 P(A|B)=P(A)。若基率 0% 或 100%，某个健康分支没有人，滑块可设定反事实分支参数，但当前总体不能据此计算该空组的条件概率。通用乘积定义仍能判断退化独立性。
CHECKPOINT · 理解检查

想算“已知阳性时有病的概率”，四格表应该用哪一组人数作分母？

READ THE CONDITION · 分母规则

把“已知 B”翻译为“只在 B 的那一列内抽人”。先说出谁有资格进入分母，再找其中满足 A 的人。

BASE-RATE NEGLECT · 基率忽视

90% 敏感度告诉你真阳性占病人的比例；低基率的人群里无病人数很多，少量的假阳性率也可能带来大量假阳性。

NOT A DIAGNOSIS · 模型适用范围

本例是教学用假想检测，不是实际诊断建议。现实检测参数会受人群、阈值、取样和验证方法影响；个体风险也不必等于总体基率。

LEARNING GOALS · 学习目标
  • 用同一总体填全 2×2 表。
  • 区分条件方向与联合概率。
  • 从自然频数推导贝叶斯比例。
  • 判断独立与零分母边界。
  • 用证据解释基率变化。
