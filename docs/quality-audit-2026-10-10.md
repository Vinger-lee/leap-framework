| 位置 | 问题 | 正确条件或反例 |

| 387 定义域规则 | 泛称三角函数都要排除 `sin x=±1`，反三角函数都要加单调区间 | sin/cos 定义域是全体实数；tan 要求 cos≠0，cot 要求 sin≠0。arcsin/arccos 输入范围是 [-1,1]，arctan 的输入可为全体实数。反函数分支与输入定义域不可混为一谈。 |
| 389 单调性 | “在区间上单调的函数一定有界” | `f(x)=x` 在 R 上单调而无界；`1/x` 在 (0,1) 上单调而无界。闭区间上的单调实值函数可由端点值界定，不能删除条件。 |
| 390 周期性 | “周期函数在一个周期内必有界” | 周期性本身不保证有界。例如在整数处取 0，非整数处取 `1/(x-floor(x))` 的函数处处有定义、周期为 1，却在每个周期无界。连续周期函数才有相应有界结论。 |
| 399–402 CP1 | 三个选项表示同一正确集合，只有一个标记 ok | `[1,3)∪(3,+∞)` 与 `[1,+∞)\{3}` 完全相同；前一种还重复出现两次。不是有效单选题。 |

| 484 复合函数极限 | 要求内函数 u 连续，却漏掉外函数 f 在 u₀ 连续 | `u(x)=x` 连续，令 f(0)=0、f(t)=1(t≠0)，则 `lim f(u(x))=1≠f(0)`。充分条件是 `u(x)→u₀` 且 f 在 u₀ 连续。 |
| 484 夹逼解释 | 说用 0 夹住 sin(1/x) | 正确是 `-|x|≤x sin(1/x)≤|x|`，两端趋零。 |

| 538 等价表 | `x²→x`、`x^k→x` 被列为等价关系 | `x²/x→0`，不等价；在 x→0⁺ 时，`x^k/x=x^(k−1)` 只在 k=1 时趋 1。趋零与等价不是一回事。 |
| 561–583 连续公式 | 用双向箭头把连续、可导、可微混为等价 | 实一元函数可导与可微等价，并推出连续；连续不推出可导，反例 `|x|` 在 0。连续条件是 `lim Δy=0`，不是差商极限存在。 |
| 597 零点定理 | 把存在和唯一混为同一工具结论 | 端点异号和连续保证存在，唯一性还需严格单调等额外条件。 |
| 599 分段函数 | “间断点只可能出现在分段点” | 各段表达式自身可能有奇点。必须同时检查每段的定义域和内部异常点。 |
| 614 含参极限 | 称 `(1+ax)^(1/x)` 中 a 是 e 的底 | a 是实参数，底数是 `1+ax`，在原点足够小邻域内为正，极限为 `e^a`。 |
| 728、740、1545 δ 计算器 | 称 δ 为下界/“最小 δ”，用放缩和抽样宣称精确求解与恒成立 | 满足定义的 δ 可以继续缩小，所以无最小正 δ。需要给出充分的上界选择及证明；抽样最大偏差不能证明整个邻域恒成立。 |

## 框架根因与修复

- 原 `save_benchmark_report` 只检查文字非空，无来源、例题或复核仍标记 completed。现在缺证据的报告保存为 pending，响应列出缺项；旧版无证据报告也不能直接通过门禁。
- 原门禁只在 `generate_diagnostic`，宿主可跳过诊断进入教学。现在诊断及主要教学、作答和评估入口都检查门禁。
- MCP 返回的网页规范原先是扁平输出字段，示例却使用嵌套契约，宿主不读仓库就拿不到桥接要求。现在 `get_web_component_spec` 同时返回打包后的完整 schema、宿主流程和内容质量要求，并测试与示例 schema 一致。
- 新增 `save_assessment_item`，题目必须有答案、推导、条件、独立检查才能登记。自由文本默认需宿主语义审阅，不接受 rule 评分写入状态。检查证明材料存在，不认证材料真实。
- 原网页后置验证用 reflection 事件，评分引用上一条 attempt；现在提交独立 attempt，服务端还拒绝 `raw_answer` 与 attempt 原文不一致。
- 查看调用队列原先调用 drain，导致待执行动作消失；现在预览使用 peek。
- 运行测试新增明确场景和真实 stdio 联调，CI 分开执行静态检查、浏览器场景、MCP 集成。完整工具参考从注册函数生成，避免靠手抄签名接入。
