# LEAP-V2 Front-end Example Library (examples/)

**Language**: [简体中文](README.md) ｜ **English**

This directory holds the **per-subject front-end teaching page examples** for LEAP-V2. They serve as
the reference standard for structure, components, interaction and visuals when a host agent
generates pages later.

> Produced by: Gemini web, following `../（内部示例任务书，不在本仓库）`.
>
> The directory was scaffolded by the engineering side and **only receives files**; each example
> HTML is generated by Gemini and saved in manually.

## Acceptance checklist

Verify every item before an example is accepted; **all must pass**.

- [ ] Single file, zero external CDN / zero network requests / zero external images; opens offline
- [ ] All three zones present: teaching + practice + agent output
- [ ] Output container `id="leap-interaction-output"` and `window.LEAP.getInteractionResult()`
- [ ] JSON matches `_shared/interaction-output.schema.json` exactly; field names unchanged
- [ ] **Host bridge complete**: `LEAP.hydrate()` accepts state, `LEAP.drainOutbox()` emits calls (see `_shared/leap-bridge.md`)
- [ ] **Every interaction produces the corresponding MCP call**, and `commit_assessment` carries a non-empty `raw_answer`
- [ ] **The page never computes `mastery_probability` itself**, and never sends one in a call
- [ ] Three-level progressive hints work and record `hint_level` (0/1/2/3/4)
- [ ] Feedback distinguishes `answer_error` / `reasoning_error` / `misconception`
- [ ] Partial credit is supported (not just right/wrong)
- [ ] Formulas use native MathML or SVG (**no** KaTeX / MathJax)
- [ ] All graphics are inline SVG / Canvas (no external images)
- [ ] Every interaction component required by the subject is implemented
- [ ] Layout holds at 1280px desktop and 375px mobile

### Visual acceptance (check against `../（作者维护的视觉规范，不在本仓库）` §8)

- [ ] The `:root` token block is pasted in full; no bare hex, no off-grid spacing
- [ ] A persistent "learning progress spine" (five-segment evidence rail + mastery + next review)
- [ ] All three zones separated by the five-part ZoneHeader
- [ ] The hint ladder is a **bottom-aligned, height-increasing** figure, not three flat buttons
- [ ] Level 4 requires a second confirmation and forces post-verification
- [ ] Feedback is three-part (what you got right → where it went wrong → next step) with the colour
      bar following `error_type`
- [ ] The evidence rail gains a point on every interaction
- [ ] The agent output zone is a collapsed status bar with an expandable recorder (**not a bare
      black `<pre>`**)
- [ ] No gradients, no glassmorphism, no emoji icons

## Automated verification (run this first, then review by eye)

The checklist above is encoded as executable checks. **Do not compare it by hand:**

```bash
# 1) static spec compliance (65 checks, zero dependencies)
python scripts/verify_example.py --all

# 2) runtime behaviour (real headless Chromium + authoritative JSON Schema validation)
python scripts/verify_example_runtime.py --all

# 3) privacy scan (this directory is scanned too)
python scripts/security_scan.py --root .
```

- `verify_example.py` covers **structure / contract / design tokens / anti-patterns / subject
  components / host bridge / DOM reference integrity**. A non-zero exit means the example fails.
- `verify_example_runtime.py` covers **the parts that only a real run can prove**: whether
  `getInteractionResult()` is callable, whether its return value validates against
  `interaction-output.schema.json`, whether `events` is append-only, whether `created_at` is Unix
  seconds, whether 375/1280px overflow horizontally, and **whether the host bridge actually
  works** (`hydrate()` injection taking effect, an answer producing `submit_attempt`,
  `commit_assessment` carrying `raw_answer`, and no smuggled `mastery_probability`).
- Static success ≠ runtime usable. **Run both.**

If an example is missing the host bridge, or a regenerated page dropped part of it:

```bash
python scripts/apply_leap_bridge.py --all       # inject (idempotent)
python scripts/apply_leap_bridge.py --repair    # re-insert parts a regeneration dropped
python scripts/apply_leap_bridge.py --check     # verify completeness, not just presence
```

`verify_example_runtime.py` needs `playwright` and a Chromium. If the browser is not in the default
cache, pass `--chromium <path>`. Add `--screenshots <dir>` to export full-page screenshots for
manual visual review.

## Notes

- This directory contains **no** web framework code and **no** Obsidian read/write code. Per the P0
  boundary in §36, the MCP runtime only emits specifications; page files are produced by the host
  agent (or carried by the examples here).
- To add a new subject, first extend `_shared/leap-web-spec.md` with that subject's specification,
  then add the subdirectory and naming entry.
