01 · TEACHING · 教学内容

一元一次方程 —— 等价变形与解法

学完这一节，你能把任意一元一次方程写成「未知数系数为 1」的形式，并说清每一步变形背后是「等式两边同时做了同一件事」。

预计 14 分钟　·　难度 2/5　·　先修：用字母表示数、四则运算

一元一次方程是指只含一个未知数、且未知数次数恰为 1 的等式，一般写成 a·x+b=c（其中 a≠0）。「解」就是让等式成立的那个 x 的值。

解它的核心思路只有一个：每次都对等号两边做同一件事，把 x 一层层「松绑」，直到它单独留在等号一边。这种操作称为等价变形——变形后的方程和原方程有完全相同的解。

a·x+b=c a·x=c−b　(两边同减 b) x=c−ba　(两边同除以 a，a ≠ 0)
等价变形四大原则
①　保持相等 —— 等号两边同时做同一件事，等式才继续成立。
②　移项本质 —— 「移项变号」其实是「两边同加 / 同减」，不是把符号随便翻过来。
③　系数归一 —— 未知数前的系数用「两边同除」消成 1，且除数必须非零。
④　逐步化简 —— 一次只做一种变形，每一步都仍是等价方程。

为什么「移项」不是符号魔法

初学者常把「移项变号」记成一句口诀，却说不清为什么。它的真正来源是等式两边同减：要去掉左边的 +b，就在两边都减去 b，于是 +b−b=0 消失在左边，而 −b 出现在右边。所谓「变号」，只是这次减法的结果，不是可以随意套用的规则。

四个必须分清的概念

  • ①　未知数 —— 想求的那个量，记作 x；解就是把它的系数变成 1。
  • ②　系数 —— x 前面的数 a；归一时用「两边同除以 a」。
  • ③　常数项 —— 不含 x 的数 b 与 c；用「两边同加 / 同减」搬动。
  • ④　等价 —— 原方程与变形后的方程解完全相同，这才叫「等价变形」。
CHECKPOINT · 理解检查

解方程 3·x+5=20 时，第一步「两边同减 5」之后，等号左边变成什么？

KEY FORM · 关键式子 a·x + b = c　（a ≠ 0） x = (c − b) / a

墨色 = 参数；绿色 = 最终解。除以 a 前务必确认 a ≠ 0。

MISCONCEPTION · 常见误解

「移项就是变号」——这句话只描述了表面，没说清来源。本质是两边同加 / 同减：把 +b 从左边去掉时，右边也必须同时减 b。只翻符号、不加减数，等式就被你改写了。

Q2

分步求解 3·x+5=20

每一步单独判定、单独给反馈。先写出「两边同减 5」后的式子，再写出 x 的值。错误会被区分成「算错」「变形步骤用错」「把移项当符号随便变」。

第一步：两边同减 5 后，等式应写成什么？

把等号两边都减去 5：左边 3·x+5−5 只剩 3·x；右边 20−5=15。所以应得到 3·x=15。

第二步：两边同除以 3，写出 x 的值。

把 3·x=15 的两边同除以 3：x=15÷3=5。
