# 权威来源教学设计

> [!note]- 文档状态
> 这是 2026-11-15 审定的设计记录。现行用法见[宿主接入](../../INTEGRATION_CN.md)和[课程导出](../../printing.md)。

## 目标与范围

用户选择预审来源库，首套课程使用高等数学。第一单元是单变量微积分的「从极限到导数与可导性」。
上线标准是 LEAP 只推进有可复核证据的教学节点，宿主能用原始资料解释定义、适用条件、推导和反例。
同一证据版本绑定教学 Markdown、交互 HTML、题目和解析。已有学习记录可读；恢复教学时按当前证据重验。
首版为高数建立可信来源，其他未收录领域显示证据不足并暂停正式教学。

现有 `save_benchmark_report` 把非空字段与有效 `source_index` 视为完成。真实 MCP 测试表明，一个不可访问的
`.invalid` 链接、单字符摘录、与课程无关的范围和过期时间都能解锁 `continue_lesson`。
`set_domain_grounding_skip` 也能在无理由、无来源时放行。改造应在服务端关闭这两条路径。

## 来源准入方案

| 方案 | 影响 |
|---|---|
| 预审来源库，首版采用 | 知识范围可枚举，同一材料可重现，适合严格门禁与离线复用。拓展范围需要维护预审内容。 |
| 自动发现候选来源，批准后入库 | 能加快拓展，需要额外处理候选质量、授权、来源范围和审核队列。可在预审流程运行稳定后另行接入。 |

首版由维护者审查和更新本地版本化来源包。来源准入按课程、版本和具体段落核对；整个域名的可信度不自动继承给任意页面。
依赖安装和检索不需要用户提供模型密钥。来源内容留在本地，由已有宿主负责解释和对话。

## 高数单元

| 教学点 | 证据与教学验收 |
|---|---|
| 函数极限与单侧极限 | OpenStax §2.2 的单侧极限与两侧极限关系、MIT 18.01SC 第 4 节。用分段函数检查左右不相等、极限不存在，以及函数值与极限可不同。 |
| 导数定义 | OpenStax §3.1 的差商极限、MIT 18.01SC 第 1 节。先解释割线斜率和 `h ≠ 0`，再从定义推导 `f(x)=x²` 在 `x=2` 的导数为 `4`。 |
| 可导性与连续性 | OpenStax §3.2 定理 3.1 及其后反例、MIT RES.18-001 §2.6 的可导性小节。解释可导推出连续，计算 `abs(x)` 在 `0` 的左右差商为 `−1` 与 `1`，因此连续但不可导。 |

主线按零基础自学编排，先说明函数值、两个点之间的斜率和「无限接近」的含义，再把差商化简和取极限分开。
示例和练习自行编写。知识定义引用教材或课程定位，题目和解析独立验算。数学验收要求检查 `h ≠ 0`、
内点双侧极限以及上述反例，避免只用数值趋近替代理论推导。

## 运行方式

1. **来源库。** 每个来源条目记录稳定 `source_id`、出版机构、教材版次或课程版本、规范网址、段落定位、
   审核日期与复核期限。每个证据片段记录稳定 `chunk_id`、可公开的短摘录或注明出处的自写摘要、
   对应的教学点、适用条件和内容哈希。库里也存经审核的教学主张及其 `chunk_id`。维护者复核后发布新版本。
2. **检索。** `get_grounding_sources` 在两种 MCP 档位可用。以服务器认可的课程标识和教学点过滤当前来源包，
   再用 LangChain 的文档/检索接口返回匹配段落。高数首版用教学点索引和稳定排序，避免搜索相似度决定授课范围。
   宿主能拿到可逐条读取的原文定位、摘要、条件、练习复核要求和证据版本。
3. **编排。** LangGraph 执行固定顺序的「解析课程 → 检索 → 校验证据状态和覆盖范围 → 持久化校准回执」。
   重试沿用现有请求幂等，证据回执与完成状态在同一 SQLite 事务生效。需要跨调用恢复时，以 LEAP 的数据库回执为准。
   该流程没有自主跳过检索的分支。见 [LangGraph 持久化](https://docs.langchain.com/oss/python/langgraph/persistence)和[检索流程示例](https://docs.langchain.com/oss/python/langgraph/agentic-rag)。
4. **校准。** `save_benchmark_report` 只在服务器能复核所选课程、已批准片段、教学点覆盖和关键例题检查结果时签发新回执。
   来源名称、摘录、版本和时间从预审包生成，宿主提交的 `authority`、`last_verified` 及任意 URL 不参与准入判定。
   校准回执带课程版本、片段指纹和证据格式版本。旧记录保留，只能用于阅读历史。
5. **授课。** State Guard 在诊断、正式教学、题目登记、练习复习以及打印交付使用同一证据状态。
   首版正式制品与预审版本的正文、题目和解析哈希匹配，点到片段的映射跟随制品版本。
   宿主可在批准范围内调整讲解顺序、挑选练习和提供反馈；新编解释和题目保留为草稿，
   由维护者复核并作为新版本发布。`anatomy` 的视觉证据与这一层同时执行。
   用户界面可看到教材、章节、引用版本及复核日期。需补证时，MCP 给宿主返回具体缺口和下一步工具调用。

LEAP 管理经过它的教学和制品。宿主若在聊天中直接输出未经 LEAP 检查的内容，宿主集成需明确标示该输出的状态。
检索返回的来源校验与例题/主张审核分别记录，宿主不能用来源校验回执自证一段新解释的语义正确。

## 长期复核与兼容性

- 首包包含经审查的静态来源片段，课程和校准可离线使用。发布物携带审查时间和复核期限。数学首包建议按 180 天复核，
  到期后返回 `grounding_expired`，复核通过后刷新期限。变动快的领域以后分别设置期限。
- 提供维护者按需运行的复核命令，检查原始来源的定位、片段与覆盖。运行时强制执行到期判定。只有变化的相关段落触发人工重审，导航和样式变更不应打断学习。
  临时网络失败时可继续使用有效快照。发现页面下架或内容实质变化时，维护者将包标为撤回或发布复核后的版本，并重启 MCP。
  门禁按已安装的版本、到期日和撤回状态决定是否允许新授课与新导出。学习历史保留原版本，已有本地文件仍可阅读。
- 旧 `allow_skip_domain_grounding` 字段保留用于读取历史。`create_session`、`start_learning` 及现有跳过工具均不能绕过新门禁。
  两档工具共同执行同一个守卫，新旧客户端收到明确的升级或补证说明。测试模拟来源的装载入口与正式服务隔离。
- 复核时的外部网络访问限于已批准的来源地址，不走宿主提供的任意 URL，不携带用户会话或作答信息。

## 验收

- 在 `full` 和 `quickstart` 的真实 stdio MCP 重跑伪造、过期、无来源跳过校准、跨课复用、旧会话恢复。
  这些情况返回明确缺口，状态不推进。对真正完整的高数来源包，标准流程能正常授课。
- 对高数样板从检索、校准到课程渲染、出题和答案执行端到端验证，逐点检查引用位置、数学推导和版本一致性。
- 模拟过期、撤回、来源网络失败、中断、重启与并发重试，检查有效版本可重放、过期版本被拒、证据写入与授课状态一致。
- 校验旧 DB 迁移、现有八组示例的离线预览与规范门禁、工具参考和隐私扫描。示例预览的静态检查与正式课程的证据门禁独立验收。
