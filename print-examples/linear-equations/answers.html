第 1 题先检验一个数

A。 2 × 3 + 1 = 7，和右边相等。B 的左边是 7，C 的左边是 5，D 的左边是 8，都和各自的右边不同。

第 2 题写出两边做了什么

两边减 3，得 4x = 16。两边除以 4，得 x = 4。代入原式，左边 4 × 4 + 3 = 19，与右边相等。

如果你写了 4x = 19，检查右边是否也减了 3。

第 3 题负号、括号与两边都有 x

括号前是 −1，分给两项后得到 5 − x + 2 = 2x + 1，即 7 − x = 2x + 1。两边加 x 得 7 = 3x + 1，再减 1 得 6 = 3x。两边除以 3，得 x = 2。

代回：左边 5 − (2 − 2) = 5，右边 2 × 2 + 1 = 5。

第 4 题给每一项乘上公倍数

两边同乘 4，得到 x − 3 + 2(x + 1) = 12。展开、合并得 3x − 1 = 12。两边加 1、再除以 3，得 x = 13/3。

代回原式，第一项是 (4/3) ÷ 4 = 1/3，第二项是 (16/3) ÷ 2 = 8/3，相加得 3。若右边仍写成 3，检查是否给它也乘了 4。

第 5 题x 消失时，剩下的等式说了什么？

① 所有实数都是解。 展开后两边减 3x，得到 3 = 3。这个式子没有对 x 加任何限制。

② 无解。 同样化简得到 3 = 7。每个 x 都会留下这个不成立的等式。

第 6 题从两条线的交点读出解

第一条线可以连接 (0, −3) 和 (2, 1)。第二条是穿过 (0, 3) 的水平线。图中交点为 (3, 3)。

纵坐标相等给出 2x − 3 = 3。两边加 3，得 2x = 6，所以 x = 3。代入两式，y 都等于 3。

第 7 题挑战｜参数什么时候能约掉？

m ≠ 2： m − 2 非零，可以两边同除，得到唯一解 x = m + 2。代回原式有 (m − 2)(m + 2) = m² − 4。

m = 2： 原式是 0x = 0，所有实数 x 都成立。若一开始直接约掉 m − 2，就会漏掉这一种情况。

第 8 题列式后检查实际取值

设租车时长为 t 小时，t 可为非负小数。8 + 4t = 22 得 t = 3.5 小时，代回得 22 元，且 3.5 在允许的范围内。

购票时设 n 为张数，n 必须是非负整数。方程给 n = 3.5，不是整数。三张付 20 元，四张付 24 元，所以无法刚好付款 22 元。
